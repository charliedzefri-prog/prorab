# ПРОраб pro — веб-версия

Веб-версия Android-приложения «ПРОраб» для строителей: строительные расчёты, площадь, расход материалов, объекты, сметы (работы и материалы), акты, финансы, заметки, файлы и калькулятор.

**Открыть:** https://charliedzefri-prog.github.io/prorab/

- Всё приложение — один автономный файл `index.html` (он же `prorab.html`), работает офлайн.
- Данные хранятся в браузере (localStorage). Перенос между устройствами — через «Настройки → Сохранить бэкап / Восстановить из файла».
- PDF создаётся через диалог печати браузера («Сохранить как PDF»).

## Сборка

Исходники лежат в `src/`. После изменений выполните:

```
python3 tools/build.py
```

Скрипт соберёт `index.html` и `prorab.html`.
